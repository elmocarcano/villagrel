# villagrel.it — sito ufficiale di Villa Grel

Sito statico pubblicato con GitHub Pages.

## Struttura
- `index.html` — homepage
- `assets/img/` — fotografie della villa
- `CNAME` — dominio personalizzato (villagrel.it)
- `.nojekyll` — disattiva l'elaborazione Jekyll di GitHub

## Come aggiornare
Modifica i file e fai commit: GitHub Pages ripubblica in automatico.
